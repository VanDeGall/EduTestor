# Plán činnosti ŠDK

## Účel

Plán činnosti ŠDK slúži na prehľadné plánovanie, riadenie a dokazovanie práce školského digitálneho koordinátora. Má ukázať, že činnosť ŠDK nie je náhodná technická pomoc, ale systematická odborná, metodická, koordinačná a strategická práca.

## Hlavné oblasti činnosti

| Oblasť | Príklady činností | Výstup |
|---|---|---|
| Strategická práca | digitálna stratégia, akčný plán, priority | strategický dokument |
| Metodická podpora | konzultácie, návody, ukážky | zápis, návod, odporúčanie |
| Školenia | Teams, SharePoint, AI, Forms, OneNote | osnova, prezenčná listina, spätná väzba |
| Technická koordinácia | účty, platformy, zariadenia, procesy | evidencia, návrh opatrení |
| AI v škole | pravidlá, prompty, bezpečné použitie | metodický dokument |
| Bezpečnosť a GDPR | prístupy, zdieľanie, anonymizácia | pravidlá, odporúčanie |
| Vyhodnocovanie | mesačné reporty, spätná väzba | report činnosti |

## Typy výstupov ŠDK

- plán činnosti,
- digitálna stratégia,
- akčný plán,
- metodický návod,
- zápis z konzultácie,
- prezenčná listina,
- spätná väzba zo školenia,
- report činnosti,
- odporúčanie pre vedenie školy,
- návrh pravidiel,
- evidencia techniky alebo účtov,
- analýza potrieb učiteľov,
- vyhodnotenie používania digitálnych nástrojov.

## Odporúčané mesačné vyhodnotenie

Každý mesiac má ŠDK pripraviť krátky report:

1. čo bolo naplánované,
2. čo bolo splnené,
3. aké výstupy vznikli,
4. komu bola poskytnutá podpora,
5. aké problémy sa opakovali,
6. čo treba riešiť s vedením,
7. priority na ďalší mesiac.

## Najlepší praktický postup

ŠDK by mal viesť jednoduchú evidenciu práce. Nie preto, aby sa obhajoval každý deň, ale preto, aby mal prehľadné dôkazy o tom, že jeho práca má odborný, metodický a strategický charakter.
