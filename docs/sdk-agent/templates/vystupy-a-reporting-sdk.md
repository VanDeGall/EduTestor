# Výstupy a reporting ŠDK

## Účel

Tento modul definuje, aké výstupy má ŠDK pravidelne vytvárať, aby bola jeho práca viditeľná, preukázateľná a využiteľná pre vedenie školy, učiteľov a rozvoj digitálnej stratégie.

## Základný princíp

Ak výstup neexistuje, práca ŠDK môže pôsobiť neviditeľne. Preto má agent pomáhať premieňať činnosti ŠDK na konkrétne dokumenty, tabuľky, odporúčania, reporty, zápisy a plány.

## Hlavné typy výstupov

| Typ výstupu | Účel | Frekvencia |
|---|---|---|
| Mesačný report ŠDK | prehľad vykonanej práce | mesačne |
| Ročný plán ŠDK | strategické nastavenie práce | ročne |
| Digitálna stratégia školy | rámec digitálnej transformácie | podľa potreby, aktualizácia min. ročne |
| Akčný plán | konkrétne kroky a zodpovednosti | polročne / ročne |
| Zápis z konzultácie | evidencia podpory učiteľov | priebežne |
| Návod pre učiteľov | metodická pomoc | podľa potreby |
| Plán školenia | príprava vzdelávania | pred školením |
| Vyhodnotenie školenia | spätná väzba a dôkaz | po školení |
| Návrh pravidiel AI | bezpečné používanie AI | podľa potreby |
| Argumentačný podklad | komunikácia s vedením | podľa potreby |

## Mesačný report ŠDK

### Štruktúra

1. Obdobie
2. Hlavné priority mesiaca
3. Realizované činnosti
4. Vytvorené výstupy
5. Podpora učiteľov
6. Školenia a konzultácie
7. Technické a organizačné problémy
8. Návrhy opatrení
9. Riziká
10. Priority na ďalší mesiac

```text

- [doplniť]

- [doplniť]

- [doplniť]

- [doplniť]

- [doplniť]
```

## Najvyššia hodnota pre ŠDK

Najväčšiu hodnotu majú tri výstupy:

1. Mesačný report činnosti.
2. Digitálna stratégia školy.
3. Akčný plán s merateľnými výstupmi.

Tieto výstupy ukazujú, že ŠDK pracuje systematicky, nie iba reaktívne.
