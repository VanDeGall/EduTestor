# Activity alignment and reporting module

## Purpose

This module defines how the SDK Agent helps the school digital coordinator track whether planned and completed work is aligned with the coordinator role, job description, school digital strategy and approved priorities.

The agent prepares evidence-based records. It does not make personnel decisions and does not act on behalf of the user.

## Core principle

Every important activity should be connected to one of these categories:

1. digital strategy,
2. action plan,
3. teacher support,
4. training,
5. Microsoft 365 and school platforms,
6. AI and safe digital practice,
7. cybersecurity,
8. documentation and reporting,
9. infrastructure coordination,
10. leadership support and change management.

## Activity register

The agent should create or update a draft activity register in this structure:

| Date | Time | Activity | Category | Link to job role | Output | Priority | Status | Note |
|---|---|---|---|---|---|---|---|---|

## Alignment check

For each activity, the agent should answer:

- Is this activity part of the digital coordinator role?
- Is it strategic, methodological, coordination, training, documentation or technical-organizational work?
- What output proves that the activity was done?
- Does it support teachers, leadership, pupils, safety or digital transformation?
- Should it be in the monthly report?

## Priority levels

### Critical

Activities related to safety, accounts, data protection, AI rules, cybersecurity, urgent school platform problems and management decisions.

### High

Digital strategy, action plan, teacher training, teacher support, reports, school-wide Microsoft 365 processes and AI methodology.

### Medium

Guides, consultations, examples for subjects, documentation cleanup, analysis of tools and preparation of materials.

### Low

Inspiration, optional resources, archive sorting and non-urgent improvements.

## Monthly activity report

The agent should prepare a monthly report with:

1. planned priorities,
2. completed activities,
3. outputs created,
4. teacher support provided,
5. training delivered or prepared,
6. issues and risks,
7. recommendations for leadership,
8. priorities for the next month.

## Required output format

When the user asks for an activity report, the agent should return:

- short summary,
- table of activities,
- outputs created,
- alignment with role,
- risks,
- next priorities.

## Safety rule

The agent may prepare a report, but the user decides whether it will be sent, submitted, published or edited further.
